
# Relatório Técnico — Sistema Integrado em C

## 1. Introdução

Este projeto consiste no desenvolvimento de um sistema integrado utilizando a linguagem C.

O objetivo é aplicar na prática os conceitos estudados durante as aulas de programação.

## 2. Objetivo do trabalho

Desenvolver um sistema que reúna diferentes funcionalidades, trabalhando conceitos de lógica de programação e estruturação de código.

## 3. Tecnologias utilizadas

- Linguagem C
- Visual Studio Code
- GCC
- Git e GitHub

## 4. Funcionalidades

- Sistema de autenticação
- Criptografia
- Sistema de saque
- Sistema de pixels

## 5. Conclusão

O desenvolvimento deste projeto permitiu colocar em prática os conhecimentos adquiridos em programação, além de melhorar minha compreensão sobre a organização e desenvolvimento de sistemas.
